> 🎓 **Образовательный проект**, демонстрирующий базовые принципы объектно-ориентированного программирования (ООП) на языке C#

Этот проект представляет собой интерактивную симуляцию животных, где различные виды животных взаимодействуют с окружающей средой, питаются и перемещаются. Проект является отличным примером применения основных принципов ООП: **наследования**, **полиморфизма**, **абстракции** и **инкапсуляции**.

## 🏗️ Архитектура проекта

Проект построен на принципах **SOLID** и демонстрирует классическую иерархию наследования:

```
Animal (абстрактный класс)
├── Carnivore (плотоядные) 🦁
├── Herbivore (травоядные) 🐰
└── Omnivore (всеядные) 🐻

Food (абстрактный класс)
├── Meat (мясо) 🥩
└── Plants (растения) 🌱
```

### 🎯 Принципы ООП в проекте

| Принцип | Реализация |
|---------|------------|
| **🔒 Инкапсуляция** | Сокрытие внутренних данных через модификаторы доступа |
| **🧬 Наследование** | Иерархия классов животных от базового класса `Animal` |
| **🎭 Полиморфизм** | Переопределение методов `Eat()` и `Energy()` в дочерних классах |
| **🎨 Абстракция** | Абстрактные классы `Animal` и `Food` |

## 🔬 Основные классы

### 🐾 `Animal` (абстрактный)
Базовый класс для всех животных в симуляции.

**Свойства:**
- `string Name` - Имя животного
- `decimal Weight` - Вес животного (кг)
- `Size AnimalSize` - Размеры животного (длина × ширина × высота)
- `decimal Speed` - Скорость животного (м/с)
- `List<Food> Stomach` - Содержимое желудка
- `static int Number` - Общее количество созданных животных

**Методы:**
- `abstract void Eat(Food food, int count)` - Поедание пищи
- `abstract void Eat(Food food)` - Поедание одной порции
- `void Run(decimal distance)` - Бег на расстояние
- `abstract double Energy()` - Расчет уровня энергии

### 🦁 `Carnivore` (Плотоядные)
Животные, питающиеся исключительно мясом.
- **Примеры:** Волк, Кот
- **Особенности:** Высокая скорость, эффективное усвоение мяса

### 🐰 `Herbivore` (Травоядные)  
Животные, питающиеся растительной пищей.
- **Примеры:** Овца, Белка, Корова
- **Особенности:** Медленное пищеварение, большой объем желудка

### 🐻 `Omnivore` (Всеядные)
Животные, способные питаться как мясом, так и растениями.
- **Примеры:** Медведь
- **Особенности:** Универсальность в питании, сбалансированный метаболизм

### 🍽️ Система питания
- **`Meat`** 🥩 - Высококалорийная пища для хищников
- **`Plants`** 🌱 - Низкокалорийная растительная пища

## 💡 Примеры использования

### Создание животных

```csharp
// Создание размера
Size size = new Size(1.2m, 0.6m, 0.8m);

// Создание конкретных животных
Carnivore wolf = new Carnivore("Wolf", 30, size, 10);
Herbivore sheep = new Herbivore("Sheep", 100, size, 10);  
Omnivore bear = new Omnivore("Bear", 150, size, 10);
```

### Кормление животных

```csharp
// Создание пищи
Plants salad = new Plants(1, 100);
Meat ham = new Meat(0.5m, 250);

// Кормление
wolf.Eat(ham, 2);           // Волк ест мясо
sheep.Eat(salad, 3);        // Овца ест растения
bear.Eat(ham, 1);           // Медведь ест мясо
bear.Eat(salad, 3);         // Медведь ест растения
```

### Использование фабричного метода

```csharp
// Создание животного через фабричный метод
Animal randomAnimal = Program.CreateAnimal(
    TypeAnimal.Wolf, 
    "Alpha Wolf", 
    45.5m, 
    new Size(1.5m, 0.8m, 1.0m), 
    15.0m
);
```
